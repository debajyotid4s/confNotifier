# Rules

## NEVER commit or push without explicit permission

- Do NOT run `git add`, `git commit`, or `git push` unless the user explicitly says "commit", "push", "stage", or similar.
- When you find a bug or issue:
  1. Explain what is wrong and why
  2. Explain how it can be fixed
  3. Wait for the user to tell you to implement the fix
  4. After implementing, wait for the user to review
  5. Only commit/push when the user explicitly says to
- This applies to ALL git operations, not just push.
- The user reviews every change before it goes to git.
